## ⚡ QUICK START COMMANDS

```bash
# 1. Install tools
pip install yt-dlp requests python-dotenv

# 2. Download a video
cd ml_training/external_videos/tier1_ted
yt-dlp -o "%(title)s.%(ext)s" "TED_TALK_URL"

# 3. Create metadata (copy template)
cp ../TEMPLATE_video_metadata.json "video_name.json"

# 4. Submit to RecCloud
python ml_training/scripts/submit_external_videos.py submit --phase 1

# 5. Check status
python ml_training/scripts/submit_external_videos.py status

# 6. Process transcripts
python ml_training/scripts/process_external_transcripts.py --phase 1

# 7. Merge all data
python ml_training/scripts/merge_external_native.py
```
