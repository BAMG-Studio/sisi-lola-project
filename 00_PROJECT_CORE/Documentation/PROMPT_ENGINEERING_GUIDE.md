## 6. QUALITY CONTROL CHECKLIST

### Before Accepting Any Generation:

**Character Assets:**
- [ ] Face matches reference seed (45822)
- [ ] Skin tone is accurate (deep melanin, warm undertones)
- [ ] Holographic markings are subtle, not overwhelming
- [ ] Expression is natural and matches prompt
- [ ] Lighting is professional and flattering
- [ ] Resolution meets minimum specs (4K+)
- [ ] No anatomical errors or distortions

**Environment Assets:**
- [ ] Atmosphere matches intended mood
- [ ] Lighting is cinematic and well-balanced
- [ ] No visible artifacts or glitches
- [ ] Perspective is correct (especially for 360°)
- [ ] Color grading is consistent with brand palette
- [ ] Resolution meets specs (6K-8K for VR)

**Video Assets:**
- [ ] Motion is smooth and natural
- [ ] No warping or morphing artifacts
- [ ] Framerate is consistent (60fps minimum)
- [ ] Audio sync is perfect (if applicable)
- [ ] Color grading is professional
- [ ] Duration matches requirements

## 10. TROUBLESHOOTING

### Problem: Inconsistent Faces
**Solution:** 
- Verify seed number (45822)
- Include "same face, character consistency" in every prompt
- Use first successful generation as image reference (img2img)

### Problem: Wrong Skin Tone
**Solution:**
- Emphasize "deep melanin skin, dark skin tone"
- Add "African woman, Nigerian heritage"
- Use negative prompt: `--no light skin, pale, caucasian`

### Problem: Over-Stylized Results
**Solution:**
- Add "photorealistic, hyper-realistic"
- Use `--style raw` in Midjourney
- Lower stylize value
- Reference professional photography

### Problem: Holographic Effects Too Strong
**Solution:**
- Use "subtle holographic glow"
- Specify "minimal digital effects"
- Adjust in post-processing if needed
