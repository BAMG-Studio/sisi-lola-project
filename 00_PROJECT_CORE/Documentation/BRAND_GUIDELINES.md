## 6. CONSISTENCY PROTOCOLS

### 6.1 Character Consistency Rules

**CRITICAL FOR ALL GENERATIONS:**

1. **Always use SEED 45822** for character images
2. **Include phrase:** "same face, same person, character consistency"
3. **Reference first generated model sheet** as style guide
4. **Maintain these unchangeable features:**
   - Face shape
   - Eye shape and position
   - Nose structure
   - Lip fullness
   - Skin tone
   - Facial proportions

5. **Variables allowed:**
   - Hairstyles
   - Makeup (minimal to moderate)
   - Outfits
   - Expressions
   - Lighting/environment

### 6.2 Quality Standards

**Minimum Specifications:**
- Images: 4K resolution (3840x2160)
- Video: 4K 60fps (VR content: 6K 90fps+)
- Audio: 48kHz 24-bit
- 3D Models: High poly (1M+ vertices for close-ups)

**Post-Processing Requirements:**
- Color grading: LUT_AfroFuture_Warm.cube
- Skin tone accuracy: Critical priority
- Holographic effects: Subtle, not overwhelming
- Lighting: Cinematic, 3-point minimum

## 9. TECHNICAL SPECIFICATIONS

### 9.1 File Formats

**Images:**
- Master: PNG (16-bit, no compression)
- Web: WebP (optimized)
- Print: TIFF (if needed)

**Video:**
- Master: ProRes 4444 or H.265 (HEVC)
- Delivery: MP4 H.265
- VR: Equirectangular MP4, spatial audio

**Audio:**
- Master: WAV 48kHz 24-bit
- Delivery: AAC 320kbps or FLAC

**3D Models:**
- FBX (Unreal/Unity compatible)
- USD (Universal Scene Description)
- OBJ (legacy support)

### 9.2 Naming Conventions

```
[CATEGORY]_[SUBCATEGORY]_[DESCRIPTION]_v[VERSION].[EXT]

Examples:
AVT_REF_SisiLola_FullBody_v01.png
ENV_STUDIO_MainLounge_Wide_v03.jpg
VID_COMMERCIAL_TechReview_30sec_v02.mp4
AUD_VOICE_Introduction_Professional_v01.wav
```
