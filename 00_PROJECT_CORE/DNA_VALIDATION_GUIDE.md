# DNA Validation Testing - User Guide

## What This Does

The DNA validation tests verify that every image generated by the system maintains **visual consistency** with your reference images (`sisi_dna_v1.png` and `sisi_dna_v2.png`).

## How to Run

### Quick Test (Recommended First)
```bash
cd /mnt/c/Users/POK28/Dropbox/Sisi_Lola/00_PROJECT_CORE/Scripts
python3 quick_dna_test.py
```

This will:
1. Check if the API is online
2. Generate a single test image
3. Validate DNA prompt injection
4. Check reference image usage
5. Give you a PASS/FAIL result

### Full Validation Suite
```bash
python3 dna_validation_test.py
```

This runs 3 comprehensive tests:
- **Studio Portrait** (1:1 aspect ratio)
- **Full Body Shot** (9:16 aspect ratio)
- **Close-up Portrait** (4:5 aspect ratio)

## Understanding the Results

### ✅ PASS Criteria
- Status: `success`
- DNA keywords found: At least 4/5 (voluptuous, yoruba, mature, hourglass, luminous skin)
- Reference images: At least 1 detected
- DNA Integrity: `100%`

### ❌ FAIL Indicators
- Missing DNA keywords in the prompt
- No reference images detected
- Generation status: `error` or `simulation`

## What to Do If Tests Fail

### Problem: "SIMULATION MODE" message
**Solution:** The KLINGAI_API_KEY is missing or invalid.
```bash
# Check your .env file
cat /mnt/c/Users/POK28/Dropbox/Sisi_Lola/sisi_lola_api/.env
```

### Problem: Missing DNA keywords
**Solution:** The `VISUAL_PROMPT_CORE` in `app/config.py` needs refinement.
1. Open `sisi_lola_api/app/config.py`
2. Edit the `VISUAL_PROMPT_CORE` to be more specific
3. Restart the server
4. Re-run the test

### Problem: No reference images detected
**Solution:** Ensure the DNA images are in the correct location.
```bash
# Check if files exist
ls -la /mnt/c/Users/POK28/Dropbox/Sisi_Lola/sisi_lola_api/assets/dna/
```

Expected files:
- `sisi_dna_v1.png`
- `sisi_dna_v2.png`

## Test Outputs

All test results are saved in:
- **Quick Test:** `quick_test_result.json` (in Scripts folder)
- **Full Suite:** `dna_validation_tests/` folder with timestamped reports

## Advanced: Custom Test Scenarios

You can add custom test scenarios by editing `dna_validation_test.py`:

```python
TEST_SCENARIOS = [
    {
        "name": "Your Custom Test",
        "scenario": "your detailed scene description here",
        "aspect_ratio": "16:9",
        "expected_features": ["feature1", "feature2"]
    }
]
```

## When to Run These Tests

1. **Before Mass Generation:** Run quick test to ensure DNA is working
2. **After Config Changes:** Run full suite after editing `VISUAL_PROMPT_CORE`
3. **Quality Audits:** Run periodically to ensure consistency across batches
